# PROJECT_OVERVIEW

## Назначение (из материалов репозитория)

- Корневой **README.md** описывает проект как веб-портал **Voensovet.ru** для поддержки военнослужащих с интеграцией AI-ассистента «Комбат».
- В **index.html** указаны заголовок страницы **Veterans Support Portal** и счётчик **Yandex.Metrika** (идентификатор виден в разметке).

Цель «приложение для помощи военным и семьям, в первую очередь вернувшимся с зоны боевых действий» задана владельцем продукта в рабочем процессе; в коде явно зафиксированы формулировки про поддержку военнослужащих и ветеранский портал (см. README и заголовок SPA).

## Техническая упаковка (фактически в репозитории)

- Одно дерево исходников с **фронтендом в корне** (`src/`, Vite + React) и **бэкендом в подкаталоге** `server/` (Node.js, Express). Отдельного метарепозитория или workspaces в `package.json` корня нет.
- Имя npm-пакета в корневом **package.json**: `magic-patterns-vite-template` (шаблонное имя; имя продукта в документации и README — Voensovet).

## Сопутствующая документация вне AI-памяти

В корне репозитория уже есть множество markdown-файлов по деплою, БД и окружению (README указывает на них). **Единственный источник истины для протокола AI — каталог `docs/ai/`.**
