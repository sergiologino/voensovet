# Проводник ветерана

## Текущее состояние

- Прототип доступен по `#navigator`. Общие и региональные демонстрационные сценарии находятся в `src/data/navigator.ts`; регион берётся из `RegionContext`, который синхронизируется с полем учётной записи `users.region_id`.
- Поддержаны темы работы, своего дела, обучения, здоровья, строительства дома, жилья/переезда и выплат. Вопрос определяется простыми локальными правилами; неизвестный вопрос требует выбора плашки.
- Выбираются четыре целевые группы: ветеран с удостоверением, участник при оформлении статуса, член семьи, семья погибшего. Выбор группы предварительно фильтрует проверенные карточки; отдельные условия всё равно нужно сверять перед обращением.
- В серверный каталог при инициализации БД добавляются десять начальных карточек по проверенным официальным страницам. Проводник запрашивает опубликованные меры сервера; при недоступном API оставляет только демонстрационные сценарии. Короткая анкета сохраняется на сервере и даёт объяснимый первичный подбор; прогресс и реальные вакансии ещё не реализованы.

## Проверенные механизмы начального каталога

- Федеральный: соцконтракт на предпринимательство до 350 000 ₽ для участников СВО или их супругов при инвалидности участника I/II группы. Требуются рекомендация фонда «Защитники Отечества», учёт в службе занятости и проверка предпринимательских компетенций либо обучение; доход семьи по специальному порядку не оценивается. [Минтруд России](https://mintrud.gov.ru/vozmozhnosti/uchastnikam-svo-i-semyam).
- Владимирская область: целевой сертификат многодетной семье вместо бесплатного участка, который можно направить на строительство дома в области; сумма в 2026 году — 289 401 ₽. Мера основана на многодетности, а не на статусе ветерана. [Соцзащита Владимирской области](https://kolchugino.social33.ru/novosti/glavnye-novosti/mnogodetnye-semi-mogut-poluchit-denezhnyy-sertifikat-vzamen-zemelnogo-uchastka082026/).
- Калужская область: бесплатный участок под индивидуальное жилищное строительство предусмотрен для награждённых участников СВО с удостоверением ветерана боевых действий и определённых законом семей погибших; нужна постановка на учёт. [Администрация города Калуги](https://www.kaluga-gov.ru/gradostroitelstvo/zemelnye-uchastki/predostavlenie-zemelnykh-uchastkov/voennosluzhashchim/62139/).
- Город Калуга: обладатель права на участок, проживающий в городском округе при указанных в услуге условиях, может выбрать 200 000 ₽ вместо участка. Это альтернатива участку, не целевая строительная субсидия. [Администрация города Калуги](https://www.kaluga-gov.ru/gosserv/for/148/allservice/246/62683/).
- Федеральные: ЕДВ ветерану боевых действий по подтверждённому статусу. [СФР](https://sfr.gov.ru/grazhdanam/socialnaya_podderzhka/federal_beneficiaries/edv/).
- Федеральные: помощь кадрового центра в поиске работы. [Минтруд](https://mintrud.gov.ru/employment/270).
- Федеральные: бесплатное переобучение по нацпроекту «Кадры»; начальная карточка ограничена концом 2026 года до повторной проверки набора. [Минтруд](https://mintrud.gov.ru/obrazovanie/).
- Федеральные: реабилитация и санаторное лечение в центрах СФР, а также технические средства реабилитации по отдельным основаниям. [Минтруд](https://mintrud.gov.ru/vozmozhnosti/uchastnikam-svo-i-semyam).
- Федеральные: выплата на ремонт частного дома для отдельных семей, потерявших кормильца; круг получателей ограничен условиями СФР. [СФР](https://sfr.gov.ru/grazhdanam/socialnaya_podderzhka/Military_families/repair).

## Целевая модель MVP

- Первая анкета подбора: целевая группа и этап оформления статуса, наличие инвалидности, родство для членов семей, число детей, жилищная ситуация. Для семей погибших — отдельная целевая группа. Хранится в `navigator_profiles` без ФИО и контактов; дальнейшие признаки добавлять только под конкретные проверенные условия мер.
- Каталог: ID меры, название, тема, уровень (федеральный или региональный), регион, статус публикации, условия и исключения, документы, ведомство, адрес/способ обращения, сроки, ссылка на первоисточник, дата последней проверки и ответственный редактор.
- Городские меры хранятся с обязательным регионом и отдельным полем населённого пункта; публичная выдача скрывает их до выбора совпадающего населённого пункта. Дата `date_end` исключает завершившиеся меры, а фильтр «Проверить источник» показывает карточки без даты проверки или с проверкой старше 90 дней.
- Подбор: обезличенные признаки анкеты → детерминированная проверка `match_rules`, включая целевую группу и регион учётной записи → список возможных мер с причинами показа и оставшимися проверками → шаги из карточек. Сохранённый прогресс запланирован следующим шагом. Неподтверждённое право на меру нельзя выдавать за одобренное.
- Персональные контакты/ФИО отделять от признаков подбора и не включать в запросы внешних сервисов. Существующий AI-помощник передаёт наружу только общий вопрос по теме, а проводник не вызывает внешний AI; для будущей анкеты и каталога требуется отдельная проверка доступа, сроков хранения и удаления данных.

## Источники для наполнения

- Федеральные: [раздел СФР об участниках СВО](https://sfr.gov.ru/grazhdanam/svo), [раздел Минтруда](https://mintrud.gov.ru/vozmozhnosti/uchastnikam-svo-i-semyam).
- Владимирская область: [навигатор МФЦ](https://mfc33.ru/svo/servises-for-svo/), [социальный навигатор региона](https://vszn.avo.ru/).
- Калужская область: [интерактивный портал социальной защиты](https://soc.admoblkaluga.ru/services/serviceselectionsp), [портал правительства области](https://www.admoblkaluga.ru/).
- Общие разделы выше служат для дальнейшего редакционного сбора; десять карточек начального каталога содержат конкретные ссылки. Для расширения каталога остаются адреса и способы обращения по каждому муниципалитету, дополнительные проверенные меры, импорт внешних подборок и регулярная перепроверка.
