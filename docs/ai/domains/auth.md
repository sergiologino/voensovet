# Авторизация

- Локальная регистрация использует email или телефон и пароль; выбранный регион хранится в `users.region_id`.
- Яндекс ID хранится в `users.yandex_id`. Вход по Яндексу находит пользователя только по этому идентификатору. Совпадение email с локальной записью не даёт доступа к ней.
- Если email уже занят, пользователь входит в существующий аккаунт по паролю и запускает привязку Яндекса в личном кабинете. Сервер хранит хеш случайного одноразового `state` на 10 минут, привязывает его к текущей сессии и сверяет с HttpOnly cookie при callback.
- Привязка не переносит Yandex ID между аккаунтами и не создаёт второй аккаунт с тем же email. После привязки обе формы входа открывают прежний профиль, регион и историю.
